# BilionPass 业务与架构规划文档

这是规划类文档项目。面向老板、团队与 CTO，梳理 BilionPass 的业务全貌、系统边界与建设方向。

当前交付：**[业务全景说明文档](docs/site/index.html)**。单文件、自包含，可双击打开或直接分享。

同一份文档内可切换“业务全景”和“系统架构”。系统架构沿用原始图的分层，分别展示 BilionPass 与行前购的独立产品边界，并标注应用、服务、基础能力和外部对接的进度。

系统架构现已展开六个核心技术域，以及资金、结算、风控三个业务支撑域。会员域已建设完成；其余域按基础模型、可售与同步、商业规则、资金闭环、风险控制五个周期推进，不绑定日期。点击领域可查看职责、数据归属、周期产出与协作关系；产品功能定义将在下一层按产品、场景和域能力映射展开。任务计划中的六个重点项目各有独立资料页，集中存放项目范围、决策、待确认事项和资料链接。

当前另有“任务计划”页（`#/tasks`），按周甘特图展示退税、关西机场行前购、酒店对接、门票对接、台湾站建站和空手行支持优惠码的目标日期与待处理事项。

修改源文件后执行：

```bash
node tools/build-docs.mjs
```

生成器检查缺失说明页、重复名称与 ID、依赖链接、待补占位和页面路由。完成后仍需浏览器检查版式、导航和链路表达。不要直接修改生成后的 HTML。
